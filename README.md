# Reminders Card

A Home Assistant Lovelace card that lists reminders held by a sensor and lets you acknowledge them. It uses the active Home Assistant theme, so it matches the native cards in both light and dark themes.

## Installation

### HACS (custom repository)

1. In HACS, open the menu and choose **Custom repositories**.
2. Add `https://github.com/gsyates1/reminders_card` with the category **Dashboard**.
3. Install **Reminders Card** and reload the browser.

### Manual

1. Copy `reminders-card.js` to `<config>/www/reminders-card.js`.
2. Go to **Settings > Dashboards > Resources** and add `/local/reminders-card.js` as a **JavaScript module**.
3. Reload the browser.

## Requirements

The [Reminders integration](https://github.com/gsyates1/reminders_integration) must be installed and set up. The card reads `sensor.reminders` and acknowledges reminders through the integration's actions.

## Data

The card reads the `reminders` attribute of the sensor you select. The attribute is a dictionary of reminder ID (generated by the integration) to reminder text:

```json
{
  "a3f9c21e": "Take out the trash",
  "7b2d90f4": "Call the dentist"
}
```

## Actions

| Button | Integration action | Data sent |
| --- | --- | --- |
| Check icon on a reminder line | `reminders.acknowledge` | `id: <id of that reminder>` |
| **All** | `reminders.acknowledge_all` | none |

The integration removes acknowledged reminders from the `reminders` attribute. The card hides an acknowledged reminder straight away and redraws from the sensor as soon as its state changes. If the sensor still lists the reminder after 10 seconds, it is shown again.

If the integration rejects a call (for example an unknown ID, or the integration isn't loaded), the card shows an error notification and shows the reminder again. Unlike the old events, actions don't need an administrator user.

## Configuration

Add the card from the dashboard editor (search for "Reminders Card"); `sensor.reminders` is picked for you. In YAML:

```yaml
type: custom:reminders-card
entity: sensor.reminders
```

| Option | Required | Default | Description |
| --- | --- | --- | --- |
| `entity` | yes | `sensor.reminders` when added from the card picker | Sensor whose `reminders` attribute holds the reminders. |
| `title` | no | none | Header shown above the list. |
| `list_height` | no | `250px` | Height of the reminder list (any CSS length). In a sections view the list also stretches or shrinks to fill the card's grid size. |

Reminder lines never wrap. The list scrolls vertically when there are more reminders than fit, and horizontally when a line is wider than the card. The acknowledge icons stay pinned to the right edge while scrolling sideways.
